# Intelligent Support System — LangGraph + VADER + RAG + HITL

This project uses the public repository
`aniket-work/intelligent-support-system` as the conceptual base: classifier,
router, response generation, escalation, YAML configuration, and helper utilities.

The conversion adds:

- LangGraph `StateGraph` orchestration
- VADER sentiment classification exposed as a LangChain `@tool`
- policy/FAQ RAG over Markdown files
- explicit Chroma ingestion and retrieval modules
- four route decisions: `auto_resolve`, `escalate`, `refuse`, `ask_more_info`
- groundedness/confidence re-check loop with retrieval refinement
- HITL via LangGraph `interrupt()` and `Command(resume=...)`
- thread-scoped conversation memory through a checkpointer + stable `thread_id`
- SQLite audit log
- synthetic ticket queue
- end-to-end Jupyter notebook

## Safety behavior

- Every customer response is a draft; the system never sends messages.
- Exact policy evidence stored by `policy_agent` is copied from retrieved KB
  chunks, never generated by the LLM.
- If no relevant policy/FAQ is established, the system escalates.
- Refund-abuse and abusive-content requests are refused only when supported by
  the corresponding retrieved policy file.
- Low-grounding drafts are re-retrieved/refined up to a configured limit, then
  safely escalated.
- Human edits are grounded again before returning to HITL.

## Runtime baseline

Use Python 3.10+ for the current LangChain/LangGraph package generation.
The supplied requirements pin LangGraph 1.2.10, LangChain 1.3.14, langchain-openai 1.4.1, langchain-chroma 1.1.0, and langchain-text-splitters 1.1.2.

## Setup

Windows example:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.template .env
```

Edit `.env` in the project root:

```text
OPENAI_API_KEY=...
OPENAI_MODEL=...
```

## Local validation without OpenAI calls

```bat
python validate_local.py
```

This validates VADER, Chroma ingestion, and retrieval.

## Run the interactive queue

```bat
python main.py
```
